# Gesture Orbit

웹캠 손 제스처와 얼굴 필터를 활용한 브라우저 기반 마법 이펙트 앱입니다.

## 주요 기능

- MediaPipe 손 인식으로 엄지와 검지 핀치 감지
- 핀치를 1초 유지하면 에너지 오브젝트 폭발
- PNG 시퀀스 기반 마법 오브젝트/폭발 이펙트
- 얼굴 인식 기반 마법사 모자와 수염 필터
- 전체 화면형 스테이지와 반투명 하단 컨트롤 바

## 실행

```bash
npm install
npm run dev
```

브라우저에서 `http://127.0.0.1:5197`을 열고 카메라 권한을 허용하세요.

## 빌드

```bash
npm run build
```

Vite 앱이므로 Vercel에 배포할 때는 `gesture-orbit` 폴더를 프로젝트 루트로 지정하면 됩니다.
